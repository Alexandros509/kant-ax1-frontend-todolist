# To do List (JavaScript)

날짜·제목·내용으로 할 일을 추가하고, 수정·삭제·조회할 수 있는 Todo 리스트입니다.
`index.html`, `css/style.css`, `js/todo.js` 세 파일로 동작합니다.

## 시연 영상

https://github.com/user-attachments/assets/afb82c22-02c1-4886-afcc-2d42a120fd8c

빈 목록 → 할 일 추가 → 수정(수정 완료 / 취소) → 삭제 → 빈 목록 순서로 동작을 보여 줍니다.

## 실행 방법

`index.html`을 브라우저로 엽니다. 별도 설치는 필요 없습니다.
(Tailwind CSS를 CDN으로 불러오므로 인터넷 연결이 필요합니다.)

## 파일 구성

```
TodoList/
├── index.html            입력 폼, 검색·정렬 영역, 목록(ul)
├── css/style.css         헤더·버튼·카드 색상 등 Tailwind로 표현하지 않은 스타일
├── js/todo.js            데이터 관리, 화면 그리기, 이벤트 처리
└── frontend-todolist.mp4 시연 영상
```

## 기능

| 기능 | 동작 |
|---|---|
| 추가 | 날짜·제목·내용을 입력하고 **등록**을 누르면 목록에 추가됩니다. 제목이 비어 있거나 공백뿐이면 "제목을 입력하세요." 안내가 나오고 추가되지 않습니다. |
| 수정 | 항목의 **수정**을 누르면 폼에 값이 채워지고 버튼이 **수정 완료**로 바뀝니다. 수정 완료를 누르면 그 항목만 바뀝니다. 수정 중에는 항목이 목록에 그대로 남아 있습니다. |
| 수정 취소 | **취소**를 누르면 아무것도 바뀌지 않고 폼이 비워집니다. |
| 삭제 | 항목의 **삭제**를 누르면 목록에서 사라집니다. 수정 중인 항목을 지우면 수정 모드도 함께 풀립니다. |
| 조회 | 목록을 날짜 오름차순으로 보여 주고, "전체 N개 / 표시 N개"를 표시합니다. 할 일이 없으면 "할 일이 없습니다"를 보여 줍니다. |

## 구현 포인트

### 1. 데이터(배열)를 먼저 바꾸고 화면은 다시 그린다
할 일 목록은 `todos` 배열 하나가 갖고 있고, 추가·수정·삭제는 모두 이 배열을 바꾼 뒤 `render()`로 화면을 다시 그립니다.

```
사용자 입력 → 이벤트 처리 → todos 배열 변경 → render() → 화면
```

할 일 하나의 모양:
```js
{ id, date, title, content, createdAt }
```

### 2. 고차 함수로 데이터 다루기
| 함수 | 쓰는 곳 |
|---|---|
| `map` | 수정할 항목만 새 값으로 바꾼 새 배열 만들기, 배열을 `<li>` 요소로 바꾸기 |
| `filter` | 삭제할 항목 빼기, 검색어가 들어간 항목 고르기 |
| `find` | 수정 버튼을 누른 항목 찾기 |
| `sort` | 날짜순 정렬 (원본을 건드리지 않도록 `[...matched]`로 복사한 뒤 정렬) |

### 3. 이벤트 위임
수정·삭제 버튼마다 리스너를 붙이지 않고, 목록(`<ul>`)에 클릭 리스너 하나만 붙였습니다.
버튼에 `data-action="edit"` / `data-action="delete"`를 달고, `e.target.closest("button[data-action]")`로 어떤 버튼인지, `closest("li").dataset.id`로 어느 항목인지 찾습니다.
나중에 추가된 항목도 리스너를 새로 붙이지 않아도 동작합니다.

### 4. 사용자 입력을 안전하게 표시
입력값은 `innerHTML`이 아니라 `textContent`로 넣습니다. 제목에 `<img src=x onerror=alert(1)>` 같은 HTML을 넣어도 글자 그대로 보이고 실행되지 않습니다.

## 알려진 한계

- **검색·정렬 선택은 아직 연결되지 않았습니다.** 검색 칸과 정렬 선택(날짜 오름차순/내림차순) 화면과 필터·정렬 로직(`getVisibleTodos`)은 있지만, 검색 칸의 `input` 이벤트와 정렬 선택의 `change` 이벤트에 리스너가 없어 입력해도 목록이 바뀌지 않습니다.
- 새로고침하면 목록이 사라집니다(데이터를 브라우저에 저장하지 않음).
- 검색 칸과 정렬 선택에 `label`이 없습니다.
